# Anna Zhang — Voice-Controlled Liquid Dispenser

Engineering project website with interviews, design, testing, revision, future work, hardware/software notes, and supporting resources.

Live site: https://coolfalcon-pixel.github.io/

## Edit the website
- `index.html`: homepage and project content.
- `technical.html`: hardware and software notes.
- `resources.html`: report, CAD, code, and bill of materials.
- `site.css`: layout and styles.
- `app.js`: mobile navigation and chart controls.
- `VIVA.pdf`: current project report.

All website files are in the repository root. GitHub Pages publishes the `main` branch, root folder. There is no build or installation step.

The base front-end stylesheet is from the user-supplied Aero Inventor site, adapted into this standalone website. The content and figures come from Anna Zhang's project report. This repository does not include WordPress server code or account credentials.
